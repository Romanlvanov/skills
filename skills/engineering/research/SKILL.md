---

Запусти **фонового агента** для исследования, чтобы ты продолжал работать, пока он читает. Запускай его с чистым контекстным окном.

Его задача:

1. Исследуй вопрос по **первоисточникам** (официальная документация, исходный код, спецификации, собственные API поставщика), а не по чужим пересказам. Проследи каждое утверждение до источника, которому оно принадлежит.
2. Запиши находки в один Markdown-файл, указав источник каждого утверждения.
3. Сохрани файл там, где репозиторий уже хранит такие заметки: следуй существующему соглашению, а если его нет, положи файл в разумное место и скажи, куда.
