# Формат RESOURCES.md

`RESOURCES.md`: отобранный набор доверенных источников по теме. Знания для объяснений бери отсюда, а не из параметрических догадок. Мудрость приходит из перечисленных здесь сообществ.

## Структура

```md
# {Topic} Resources

## Knowledge

- [Book: _The Science and Practice of Strength Training_ by Zatsiorsky & Kraemer](https://example.com)
  Foundational text on programming and adaptation. Use for: anything to do with periodisation, recovery, intensity zones.
- [Article: "How Much Should I Train?" by Greg Nuckols (Stronger By Science)](https://example.com)
  Evidence-based review of volume landmarks. Use for: weekly set targets per muscle group.

## Wisdom (Communities)

- [r/weightroom](https://reddit.com/r/weightroom)
  High-signal subreddit, moderated against bro-science. Use for: programme critique, plateau troubleshooting.
- Local: Tuesday strength class at {gym name}
  Use for: real-time coaching feedback on lifts.
```

## Правила

- **Только высокое доверие.** Предпочитай первоисточники, признанных экспертов, рецензируемые работы и сообщества со строгой модерацией. Если ресурс оказывается маркетингом под видом обучения, не включай его.
- **Аннотируй каждую запись.** Голая ссылка через три месяца бесполезна. Добавь одну строку: что в ней и когда к ней обращаться.
- **Группируй по Knowledge / Wisdom (знания / мудрость).** Так отражается философия из [SKILL.md](./SKILL.md). Ресурс вполне может быть только в одной группе.
- **Явно показывай пробелы.** Если для области, нужной миссии, нет хорошего ресурса, напиши секцию `## Gaps` со списком того, чего не хватает. Это направляет будущий поиск.
- **Безжалостно вычищай.** Ресурс, который оказался неверным, поверхностным или не по миссии, удаляй, а не закапывай. Лучше пять острых источников, чем тридцать посредственных.
- **Фиксируй предпочтения по сообществам.** Если пользователь отказался вступать в сообщества, отметь это здесь, чтобы будущие сессии не предлагали их снова.
