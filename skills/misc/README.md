# Misc

Инструменты, которые я держу под рукой, но редко использую; в плагине не продвигаются.

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)**: настраивает хуки Claude Code, которые блокируют опасные git-команды (push, reset --hard, clean и т.п.) до их выполнения.
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)**: переводит тестовые файлы с утверждений типов `as` на @total-typescript/shoehorn.
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)**: создаёт структуру каталогов упражнений с разделами, задачами, решениями и пояснениями.
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**: настраивает pre-commit хуки Husky с lint-staged, Prettier, проверкой типов и тестами.
